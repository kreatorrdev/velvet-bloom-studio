# Velvet Bloom Studio

Aplikacija je u unutrašnjem folderu `velvet-bloom-studio/`, pored njenog `package.json` fajla.

```powershell
cd velvet-bloom-studio
npm.cmd run dev
```

Za produkcioni prikaz:

```powershell
npm.cmd run build
npm.cmd run start
```
